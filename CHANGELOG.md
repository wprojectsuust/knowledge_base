# История изменений

Формат - [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/). Версий-релизов у проекта
нет: `main` сразу выкатывается на прод, поэтому изменения сгруппированы по дням.

## Не выпущено

### Добавлено
- Тривиальные вопросы («через сколько это?», «а в каком кабинете?», «спасибо») отвечаются
  сразу из диалога и текущего времени - без поиска по базе, одним вызовом LLM (ADR 012).
- На карте: студенческий МФЦ (МФСО) - слева при входе в корпус 7, ситуационный центр - справа
  при входе в корпус 6, печатный дом между корпусами 5 и 2; библиотека - 3-5 этажи корпуса 7.
- На вопросы о мероприятиях, событиях и новостях в ответ подмешиваются 5 самых свежих
  новостей uust.ru по дате публикации.

### Исправлено
- Списки официальных документов больше не вытесняют настоящие ответы из поиска (не больше
  двух в выдаче).
- «Как добраться до главного корпуса» - ответ по базе знаний вместо «не нашёл «ф1» на карте».
- Псевдоисточники «Факт», «Фрагмент» не показываются в блоке «Источники».

### Документация
- Полная документация в `docs/`: архитектура, API, конфигурация, деплой, база знаний, карта
  кампуса, фронтенд, тестирование.
- ADR 002-011 по принятым решениям, индекс и шаблон ADR; ADR перенесены в `docs/adr/`.
- CONTRIBUTING, SECURITY, CODE_OF_CONDUCT, шаблоны pull request и issue.
- Дерево файлов переехало в `docs/tree`.

## 2026-09-30

### Добавлено
- «Второй шанс» для ответов по базе знаний: если прямого ответа нет, консультант ищет
  недостающее другими запросами (до двух дополнительных шагов) или уточняет, о ком речь.
- `POST /question/stream` (Server-Sent Events): статусы «Разбираю вопрос», «Ищу в базе
  знаний», «Ищу, кто декан…»; на фронте - крутящийся индикатор со сменяющимся текстом.
- Навигатор: подземный переход между корпусами 6 и 7 под КПП; маршрут между корпусами идёт
  тёплыми переходами, уличный вариант показывается рядом пунктиром.
- Автоимпорт списка официальных документов с `uust.ru/sveden/document/` (названия и ссылки,
  синхронизация раз в сутки без лишних вызовов LLM).
- Ответы в Markdown: списки, таблицы, ссылки.
- Мобильная версия: нижняя панель вкладок, адаптивные чат и карта.

### Изменено
- Этажность корпусов по паспортам доступности УГАТУ и OpenStreetMap (корпус 4 - 5 этажей).

### Исправлено
- Ответы больше не ссылаются на внутренние номера фрагментов (`[Источник: ID 140]`);
  источники в круглых скобках тоже выносятся в блок «Источники».
- Убран несуществующий буфет в корпусе 6 (база знаний и карта).

## 2026-09-29

### Добавлено
- CI/CD в GitHub Actions: тесты, сборка образов, доставка на сервер, проверка здоровья.
- Прод на https://karrad.tech/uunit/ за nginx; ротация логов, проверка места перед деплоем.
- Поддержка любого OpenAI-совместимого LLM API (переход на claudehub / Qwen).

### Исправлено
- Составной вопрос («смогу ли я подольше поспать, если…») получает ответ на исходный
  вопрос, а не набор ответов на подзадачи.
- Фронт ходит на бэкенд того же хоста, с которого открыт (раньше - `0.0.0.0`, блокировалось браузером).
- CORS: по умолчанию разрешены все источники.

## 2026-09-28

### Добавлено
- Next.js-фронтенд: главная, чат `/ask` с анимированным фоном, 3D-карта кампуса `/map`.
- Расписание групп из ИСУ: группа и дата из вопроса, ответ именно на заданный вопрос.
- Уточняющие вопросы (группа) с запоминанием ответа в браузере.
- 3D-карта кампуса УГАТУ по схеме UUST MAPS: корпуса, этажи, кабинеты, лестницы, переходы.
- Навигатор «как пройти из X в Y» с шаблонным текстом и линией маршрута на карте.
- Мини-карта места из ответа, «перелетающая» из угла в центр.
- Несколько вопросов в одном сообщении; история чата в браузере как контекст.
- Импорт новостей uust.ru в базу знаний.
- Страница загрузки данных в базу знаний.

### Исправлено
- Понятный `503` при перегрузке LLM вместо «ошибки CORS»; цепочка запасных моделей.
- Шторм запросов к LLM при старте (`429`): паузы в импорте, «остывание» модели после `429`.
- Нормализация названий групп, лишние уточнения, нерелевантный контекст в ответах.

## 2026-09-27

### Добавлено
- Ядро: чистая архитектура, TDD, FastAPI, PostgreSQL для документов, ChromaDB для векторов.
- Индексация фрагментов по сгенерированным LLM вопросам, эмбеддинги rubert-tiny2.
- Кэш вопрос-ответ, теги подразделений, ограничение конкурентности LLM и эмбеддингов.
- Docker Compose, Makefile, пирамида тестов (unit / integration / e2e / stress).

### Изменено
- MinIO заменён на PostgreSQL: публичные образы MinIO перестали распространяться (ADR 001).
