# Фронтенд

Next.js 15 (App Router) + React 19 + TypeScript, без UI-библиотек: стили - один
[`app/globals.css`](../frontend/app/globals.css) с CSS-переменными. 3D - three.js через
`@react-three/fiber`, `@react-three/drei`, `@react-three/postprocessing`. Markdown -
`react-markdown` + `remark-gfm`.

## Страницы

| Путь | Файл | Что делает |
|---|---|---|
| `/` | `app/page.tsx` | Главная: поиск, популярные вопросы, карточка ответа с источниками, быстрый доступ |
| `/ask` | `app/ask/page.tsx` | Чат: лента вопросов и ответов, уточнения, история в браузере, мини-карта «как пройти» |
| `/map` | `app/map/page.tsx` | 3D-карта кампуса: выбор корпуса и этажа, форма «откуда -> куда», шаги маршрута |

Общий каркас - `app/layout.tsx`: анимированный фон, боковое меню на десктопе и нижняя панель
вкладок на телефоне.

## Компоненты

| Компонент | Назначение |
|---|---|
| `Sidebar` / `MobileNav` | Навигация: боковое меню (>860 px) и нижние вкладки на телефоне |
| `Typewriter` | Печатает ответ «как ИИ» (не дольше ~1,6 с), рендерит Markdown по мере печати |
| `Markdown` | `react-markdown` + GFM; ссылки открываются в новой вкладке, сырой HTML не рендерится |
| `ThinkingIndicator` | Крутящееся кольцо и текущий шаг («Ищу в базе знаний…») из потока `/question/stream` |
| `SourcesList` | Блок «Источники» из пометок `[Источник: …]` в ответе |
| `ClarificationPrompt` | Поле ответа на уточняющий вопрос (например, группа) |
| `FactChips` | Что консультант знает о студенте; крестик - забыть |
| `VenueMap` | Мини-карта: появляется в углу и «перелетает» в центр, когда ответ допечатан |
| `campus/CampusMap` | Ленивая загрузка 3D-сцены (без SSR - three.js работает только в браузере) |
| `campus/CampusScene` | Сцена: корпуса по этажам, кабинеты (`InstancedMesh`), лестницы, переходы, подземный переход, маршрут и его уличный вариант |
| `AnimatedBackground` | Размытые плавающие пятна на фоне |

## Данные и состояние

| Модуль | Что делает |
|---|---|
| `lib/api.ts` | `apiUrl()` - адрес бэкенда; `askQuestion()` - вопрос через SSE со статусами; `buildRoute()`; разбор источников (`extractSources`, `stripSourceTags`) |
| `lib/campus-data.ts` | `useCampuses()` - `GET /campus`; перевод пикселей схемы в метры сцены |
| `lib/chatStorage.ts` | История чата в `localStorage` (`uunit.chat`) |
| `lib/useStudentFacts.ts` | Сведения о студенте в `localStorage` (`uunit.studentFacts`) |

Серверного состояния пользователя нет (ADR 005). В `/ask` с вопросом уходят 6 последних реплик.

**Адрес бэкенда.** По умолчанию - тот же хост, что у страницы, порт `8000`: фронт, открытый
с телефона по `http://192.168.1.50:3000`, ходит на `http://192.168.1.50:8000` без пересборки.
`NEXT_PUBLIC_API_BASE_URL` задаёт адрес явно (на проде - `/uunit/api`), `BASE_PATH` - префикс
приложения (`/uunit`).

## Адаптив

Точки перелома - 1280 px и 860 px. На телефоне:
- боковое меню заменяется нижними вкладками с учётом `safe-area-inset-*` («чёлка», полоска жестов);
- поля ввода 16 px - иначе iOS Safari зумит страницу при фокусе;
- ответы растягиваются во всю высоту, длинные ссылки переносятся;
- на карте поля идут столбиком, корпуса и этажи прокручиваются горизонтально, шаги маршрута -
  панель снизу; мини-карта маршрута раскрывается почти на весь экран.

## Разработка

```bash
cd frontend
npm install
npm run dev              # http://localhost:3000, бэкенд - localhost:8000
npx tsc --noEmit         # проверка типов (то же делает CI)
npm run build            # production-сборка (output: standalone)
```

Проверить вёрстку под телефон без телефона: DevTools -> режим устройства, ширина 390 px.
