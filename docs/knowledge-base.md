# База знаний

База знаний - это набор **фрагментов**: коротких текстов об учёбе, документах, подразделениях и
жизни в УУНиТ. Консультант отвечает только по ним и указывает источник.

| Поле | Где хранится | Смысл |
|---|---|---|
| `id` | PostgreSQL | Присваивает база |
| `source` | PostgreSQL | Ссылка на первоисточник; пусто - проверенный факт без ссылки |
| `content` | PostgreSQL | Сам текст фрагмента |
| `division` | PostgreSQL + Chroma | Необязательный тег подразделения (институт, факультет, служба) |
| вопросы | Chroma | 5 вопросов, на которые отвечает фрагмент: их генерирует LLM при добавлении, по ним идёт поиск |

Почему поиск идёт по сгенерированным вопросам, а не по самому тексту - ADR 004.

## Как добавить данные

### Страница загрузки

`GET /` бэкенда - простая HTML-форма: источник и текст (подразделение - только через API). Прод -
https://karrad.tech/uunit/api/.

### Через API

```bash
curl -X POST https://karrad.tech/uunit/api/data \
  -H 'Content-Type: application/json' \
  -d '{
        "source": "https://uust.ru/ospo/questions/",
        "content": "Перевод с платного обучения на бюджет возможен при наличии вакантных бюджетных мест …",
        "division": "ispo"
      }'
```

Каждое добавление - один вызов LLM. Для пачки записей шлите их **по одной**, с паузой в
несколько секунд, и повторяйте запрос при `503`/`429`:

```bash
# kb.jsonl - по одному JSON {"source", "content", "division"} на строку
while IFS= read -r line; do
  until curl -sf -X POST https://karrad.tech/uunit/api/data \
        -H 'Content-Type: application/json' -d "$line"; do sleep 60; done
  echo; sleep 3
done < kb.jsonl
```

Скрипт для большой заливки лучше запускать на самом сервере на `http://127.0.0.1:5001/data`:
так нет сетевых обрывов, и компьютер можно выключить.

### Удаление и исправление

- `DELETE /data/{id}` удаляет фрагмент и его векторы, очищает кэш ответов.
- Исправить фрагмент = удалить и добавить заново: вопросы к нему должны пересчитаться.
- Найти `id` нужного фрагмента: `POST /search` с формулировкой вопроса или SQL
  `SELECT id, left(content, 80) FROM documents WHERE content ILIKE '%…%'`.

## Как писать фрагменты

- **Один фрагмент - одна тема.** «Как получить справку об обучении» и «Где заказать
  студенческий билет» - два фрагмента, даже если источник один.
- **Контекст внутри текста.** Фрагмент читается без соседей: «Деканат ФИРТ находится в корпусе
  1, кабинет 1-212», а не «Находится в корпусе 1».
- **Размер** - от одного предложения до ~1-2 тыс. символов. Длинный документ режьте по разделам;
  заголовок раздела повторяйте в начале каждого куска.
- **Даты - в тексте** («приём заявлений до 25 сентября 2026 г.»), иначе модель не отличит
  прошлое от будущего.
- **Источник** - прямая ссылка на страницу или документ. Факты, собранные командой вручную и
  проверенные, можно добавлять без ссылки (`source: ""`): в ответе они используются без
  пометки об источнике (ADR 011).
- **Без персональных данных:** не добавляйте личные телефоны студентов и руководителей
  кружков, только официальные контакты подразделений.
- **Проверка.** Ложный факт хуже отсутствующего: если сомневаетесь, не добавляйте.

## Автоимпорт с uust.ru

Бэкенд сам подтягивает два источника (ADR 008):

| Источник | Как часто | Что попадает в базу |
|---|---|---|
| Лента новостей `uust.ru/news/` | раз в `NEWS_IMPORT_INTERVAL_MINUTES` (180), последние 14 | Текст новости с датой и заголовком; `source` - ссылка на новость |
| Документы `uust.ru/sveden/document/` | раз в `DOCUMENTS_IMPORT_INTERVAL_HOURS` (24) | Только названия и ссылки, порциями по 20 внутри раздела; ~960 документов -> ~100 записей |

- Уже загруженные новости не скачиваются повторно (сверка по ссылке).
- Порция документов, которая не изменилась, не стоит ни одного вызова LLM. Изменившаяся
  перезаливается, устаревшая удаляется.
- Если сайт недоступен или сменил вёрстку, база не трогается.
- Вручную подтянуть новости - `POST /news/import`.

## Как проверить качество

1. `POST /search` с типичной формулировкой студента - нужный фрагмент должен быть в выдаче.
2. Если не находится - посмотрите DEBUG-логи `SearchDataByListOfStr`: какое сходство у
   фрагмента. Ниже `SEARCH_SIMILARITY_THRESHOLD` - переформулируйте фрагмент ближе к языку
   студентов или разбейте на части.
3. Задайте вопрос в чате: ответ должен опираться на фрагмент и показывать его источник.
