# Конфигурация

Бэкенд читает переменные окружения, в docker compose - из файла `.env` в корне репозитория.
Шаблон - [`.env.example`](../.env.example): `make env` копирует его в `.env`, если файла ещё нет.
Числовые настройки с комментариями собраны в [`backend/src/config.py`](../backend/src/config.py).

> `.env` в git не коммитится. Ключи API не должны попадать ни в код, ни в логи, ни в issue.

## LLM

| Переменная | По умолчанию | Смысл |
|---|---|---|
| `LLM_BASE_URL` | эндпоинт Gemini | Адрес любого OpenAI-совместимого API |
| `LLM_API_KEY` | - | Ключ. **Если пуст - используются `GEMINI_*`** |
| `LLM_MODEL` | модели Gemini | Модель или несколько через запятую: первая основная, остальные запасные |
| `GEMINI_API_KEY` | - | Ключ Gemini (запасной вариант, если `LLM_API_KEY` пуст) |
| `GEMINI_MODEL` | `gemini-3.6-flash,gemini-2.5-flash,…` | Цепочка моделей Gemini |
| `PROXY_URL` | - | SOCKS5/HTTP-прокси до LLM, если нет прямого доступа |
| `LLM_MAX_CONCURRENCY` | `5` | Одновременных запросов к LLM с одного инстанса |
| `LLM_MAX_RETRIES` | `2` | Повторов на модель при `5xx`/таймауте (на `429` не повторяем) |
| `LLM_RATE_LIMIT_COOLDOWN_SECONDS` | `60` | Сколько модель «остывает» после `429` |
| `LLM_TIMEOUT_SECONDS` | `45` | Таймаут одной попытки |
| `LLM_TOTAL_BUDGET_SECONDS` | `90` | Бюджет на весь вызов со всеми повторами и запасными моделями |

Сейчас на проде - claudehub (`https://api.claudehub.fun/v1`, модель `Qwen-3.8-Max`). Почему так
устроено - ADR 003.

## Хранилища

| Переменная | По умолчанию | Смысл |
|---|---|---|
| `POSTGRES_USER` / `POSTGRES_PASSWORD` / `POSTGRES_DB` | `uunit` | Учётка и база PostgreSQL |
| `POSTGRES_HOST` | `localhost` (в compose - `postgres`) | Хост PostgreSQL |
| `POSTGRES_PORT` | `5432` | Порт PostgreSQL |
| `CHROMA_PATH` | `./chroma_db` (в compose - `/data/chroma_db`) | Каталог персистентного клиента Chroma |

## Поиск и ответы

| Переменная | По умолчанию | Смысл |
|---|---|---|
| `SEARCH_SIMILARITY_THRESHOLD` | `0.5` | Минимальное косинусное сходство фрагмента, чтобы попасть в контекст LLM |
| `SCHEDULE_DIRECTIONS_SIMILARITY_THRESHOLD` | `0.55` | То же для подсказки «как добраться» в ответе о расписании |
| `EMBEDDING_MAX_CONCURRENCY` | `5` | Одновременных вычислений эмбеддингов (CPU) |
| `SCHEDULE_CACHE_TTL_SECONDS` | `3600` | Сколько расписание из ИСУ считается свежим |

Порог сходства калибруется по DEBUG-логам `SearchDataByListOfStr`: там видны оценки найденных фрагментов.

## Автоимпорт с uust.ru

| Переменная | По умолчанию | Смысл |
|---|---|---|
| `NEWS_IMPORT_INTERVAL_MINUTES` | `180` | Как часто проверять ленту новостей; `0` - только вручную (`POST /news/import`) |
| `NEWS_IMPORT_LIMIT` | `14` | Сколько свежих новостей проверять за раз |
| `NEWS_IMPORT_PAUSE_SECONDS` | `20` | Пауза между вызовами LLM при любом фоновом импорте |
| `DOCUMENTS_IMPORT_INTERVAL_HOURS` | `24` | Как часто синхронизировать список документов; `0` - выключено |
| `DOCUMENTS_IMPORT_BATCH_SIZE` | `20` | Сколько документов в одной записи базы знаний |

Первый прогон новостей - через минуту после старта, документов - через 5 минут. Подробнее -
[knowledge-base.md](knowledge-base.md#автоимпорт-с-uustru), ADR 008.

## Сервер

| Переменная | По умолчанию | Смысл |
|---|---|---|
| `FRONTEND_ORIGIN` | `*` | Разрешённые CORS-источники: `*` или адреса через запятую. Куки и авторизации нет, поэтому `*` безопасен |
| `LOG_LEVEL` | `DEBUG` в `.env.example` | Уровень логов. DEBUG показывает запросы к API, БД, LLM и что нашлось. На проде - `INFO` |

## Фронтенд (на этапе сборки)

| Переменная | По умолчанию | Смысл |
|---|---|---|
| `NEXT_PUBLIC_API_BASE_URL` | пусто | Адрес бэкенда. Пусто - тот же хост, что у страницы, порт `8000` (удобно открывать с телефона по IP) |
| `BASE_PATH` | пусто | Префикс пути приложения, если сайт живёт не в корне домена (на проде - `/uunit`) |

Обе переменные - `ARG` в [`frontend/Dockerfile`](../frontend/Dockerfile), они «зашиваются» в сборку.
