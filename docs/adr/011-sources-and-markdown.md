# 011. Источники в ответах и Markdown

## Статус

Принято

## Контекст

Консультант должен показывать, откуда взят ответ. Но часть базы знаний - проверенные факты,
собранные командой вручную, без ссылки. Когда в контекст LLM попадал внутренний id записи,
модель «цитировала» его: `[Источник: ID 140]` - бессмысленно для студента. Кроме того, модель
писала пометку то в квадратных, то в круглых скобках, а ответы со списками и таблицами
выводились сплошным текстом.

## Решение

- В контекст LLM фрагмент попадает как `[Источник: <ссылка>]` или как `[Фрагмент]`, если
  источника нет. Внутренний id в промпт не передаётся.
- Правило в промпте: источник указывается строго в формате `[Источник: …]` и только для
  фрагментов, у которых он есть; факты без источника используются без ссылок.
- Фронт распознаёт `[Источник: …]` и `(Источник: …)` (несколько через `;`), выносит их в блок
  «Источники» и вырезает из текста; пометки вида `ID 140` отбрасываются.
- LLM оформляет ответ в Markdown; фронт рендерит его через `react-markdown` + `remark-gfm`
  (списки, таблицы, ссылки в новой вкладке), сырой HTML не рендерится.

## Последствия

- Защита двойная (промпт + фронт): даже если модель нарушит правило, студент не увидит `ID`.
