# 006. Уточняющий вопрос вместо угадывания

## Статус

Принято

## Контекст

«Во сколько у меня завтра кончаются пары?» без группы не имеет ответа. Угадывать группу или
отвечать «уточните, пожалуйста» простым текстом - плохой опыт: студенту приходится
переписывать вопрос целиком.

## Решение

- Планировщик может вернуть `clarify: {field, question}` - только когда студент просит **свои**
  данные, а их нет ни в сообщении, ни в `facts`, ни в истории. Общие вопросы («как узнать
  расписание своей группы») не уточняются.
- API отвечает `clarification` вместо `answer`; фронт показывает поле для ответа, запоминает
  значение как факт и повторяет **тот же** вопрос с `facts`.
- Защита от зацикливания: если LLM снова спрашивает уже известное поле, уточнение игнорируется.
- Поиск со «вторым шансом» (ADR 009) тоже может уточнить («декан какого факультета?»), но
  только один раз: если студент уже что-то сообщил, отвечаем тем, что есть.

## Последствия

- Студент отвечает одним словом («ТОП-106Б»), а не переписывает вопрос.
- Группа запоминается - следующие вопросы про расписание не требуют уточнения.
