## Когда писать ADR

- выбираем технологию или внешний сервис (база, LLM-провайдер, способ деплоя);
- меняем устройство, которое затрагивает несколько слоёв (формат API, пайплайн ответа);
- отказываемся от ранее принятого решения - тогда новый ADR, а у старого статус
  «Заменено ADR NNN».

Номер - следующий по порядку, имя файла - `NNN-коротко-по-английски.md`. Принятые ADR не
переписываем задним числом: решение изменилось - пишем новый.
