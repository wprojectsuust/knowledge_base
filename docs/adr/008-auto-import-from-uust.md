# 008. Автоимпорт с uust.ru: новости по ссылке, документы порциями с хэшем

## Статус

Принято

## Контекст

База знаний устаревает, если наполнять её только руками. На uust.ru есть лента новостей и
страница «Документы» (~1000 положений, приказов и шаблонов). API у сайта нет.

## Решение

- **Новости** (`ImportNews`): фоном раз в `NEWS_IMPORT_INTERVAL_MINUTES` берутся последние
  `NEWS_IMPORT_LIMIT` карточек ленты. Ссылка новости - это `source` записи: уже загруженные
  пропускаются без скачивания. Дата и заголовок пишутся в текст, чтобы ответ отличал прошедшее
  мероприятие от будущего.
- **Документы** (`ImportDocuments`): со страницы `sveden/document` берутся только названия и
  ссылки (сами файлы не качаются). Свёрнутые блоки-аккордеоны уже есть в HTML - JS не нужен.
  Документы режутся на порции по 20 внутри раздела/подраздела; `source` порции = адрес
  страницы + хэш её текста.
  - порция не изменилась - пропускаем без вызова LLM;
  - изменилась - новая индексируется, устаревшая удаляется, но только если все новые
    загрузились (иначе в базе была бы дыра);
  - пустая страница (сайт лежит, сменилась вёрстка) базу не трогает.
- Между вызовами LLM - пауза `NEWS_IMPORT_PAUSE_SECONDS`, при недоступности LLM импорт
  прерывается и доберёт остальное в следующий прогон.

## Последствия

- Первый прогон документов - около сотни вызовов LLM, дальше - только изменения.
- Парсинг привязан к вёрстке uust.ru; при её смене импорт перестанет находить записи, но не
  испортит базу. Разбор покрыт тестами на сохранённых HTML-фикстурах.
