# 005. Без аккаунтов: история чата и сведения о студенте хранятся в браузере

## Статус

Принято

## Контекст

Для контекста диалога («а туда как пройти?») и персональных ответов («какие у меня завтра
пары») нужно помнить прошлые реплики и группу студента. Регистрация, логины и серверные сессии
- лишний барьер для первого вопроса и лишние персональные данные на сервере.

## Решение

- История чата (`/ask`) хранится в `localStorage` браузера; с каждым вопросом фронт присылает
  6 последних реплик (`history`; API принимает не больше 10).
- Сведения, которые студент сообщил в ответ на уточнение (группа, факультет), хранятся там же
  и отправляются как `facts`; их можно удалить крестиком на чипе.
- Сервер ничего из этого не сохраняет. Ответы кэшируются только без истории, и в промпте
  запрещено упоминать личные данные - кэшированный ответ может увидеть другой студент.

## Последствия

- Нет аккаунтов, паролей и базы пользователей - нечего защищать и нечего утечь.
- История не синхронизируется между устройствами - для консультанта это приемлемо.
