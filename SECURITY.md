# Безопасность

## Как сообщить об уязвимости

**Не создавайте публичный issue.** Напишите в Telegram [@karrrad](https://t.me/karrrad):
что нашли, как воспроизвести, чем грозит. Ответим в течение пары дней и сообщим, когда исправим.

## Что мы храним

- **Нет аккаунтов и персональных данных пользователей.** История чата и сведения о студенте
  (например, группа) хранятся только в браузере (`localStorage`); сервер получает их вместе с
  вопросом и не сохраняет (ADR 005).
- **Кэш ответов** хранит пары «вопрос -> ответ» без истории чата. В промпте LLM запрещено
  упоминать личные данные из вопроса - кэшированный ответ может увидеть другой студент.
- **База знаний** - только официальная информация вуза; личные телефоны и данные студентов
  и сотрудников не добавляются (см. [CONTRIBUTING.md](CONTRIBUTING.md#данные)).
- **Логи** не содержат ключей API; на проде уровень `INFO`, логи ротируются (3 × 10 МБ).

## Секреты

- Ключи LLM и пароли БД - только в `.env` на сервере; файл в `.gitignore` и деплоем не перезаписывается.
- Доступ CI к серверу - отдельный deploy-ключ в секретах репозитория (environment `production`).
- PostgreSQL наружу не публикуется, бэкенд и фронт слушают только `127.0.0.1` за nginx с HTTPS.

## Известные ограничения

| Что | Риск | План |
|---|---|---|
| `POST /data`, `DELETE /data/{id}`, `POST /news/import` и страница загрузки - **без авторизации** | Кто угодно может добавить или удалить фрагмент базы знаний | Токен администратора для изменяющих эндпоинтов |
| CORS `*` по умолчанию | Сторонний сайт может вызывать API из браузера посетителя; кук и сессий нет, поэтому утечь нечему | Ограничить `FRONTEND_ORIGIN` адресом сайта |
| Нет ограничения частоты запросов | Можно выесть лимит LLM API | Rate limit на nginx для `/uunit/api/question` |
| Ответы генерирует LLM | Возможны неточности при корректной базе | Ответ строится только по найденным фрагментам со ссылкой на источник; жалобы - в Telegram |

## Поддерживаемая версия

Поддерживается только текущий `main` - он же развёрнут на https://karrad.tech/uunit/.
